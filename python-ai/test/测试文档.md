# Python AI 引擎自动化测试文档

## 概述

本测试套件包含两类测试：
1. **单元测试**（263 个）：纯逻辑函数测试，不依赖外部服务，可直接运行
2. **API 集成测试**（45 个）：Java 后端接口测试，需要后端运行在 `localhost:8085`

总计 **308 个测试用例**。

## 运行方式

### 运行全部测试
```bash
cd python-ai
python -m pytest test/ -v
```
- 后端运行时：308 个全部执行
- 后端未运行时：263 个单元测试执行，45 个 API 测试自动跳过

### 仅运行单元测试（不需要后端）
```bash
python -m pytest test/ -v -k "not test_api"
```

### 仅运行 API 测试（需要启动 Java 后端）
```bash
python -m pytest test/test_api_*.py -v
```

### 运行指定文件
```bash
python -m pytest test/test_permissions.py -v
python -m pytest test/test_api_auth.py -v
```

### 运行指定测试类
```bash
python -m pytest test/test_tools.py::TestIsBlank -v
```

### 运行指定测试用例
```bash
python -m pytest test/test_formatters.py::TestExtractTaggedText::test_present_tag -v
```

### 查看覆盖率
```bash
pip install pytest-cov
python -m pytest test/ --cov=story_ai_pkg --cov=chat_agent_pkg --cov=ai_runtime --cov-report=term-missing
```

## API 测试说明

API 测试通过 Python httpx 客户端调用 Java 后端 REST 接口，测试真实 HTTP 请求/响应。

### 前置条件
- Java 后端运行在 `http://localhost:8085`
- MySQL、Redis、RabbitMQ 正常运行
- 数据库已执行 `init.sql` 初始化

### 自动检测机制
`conftest.py` 中的 `_check_server_available()` 会尝试连接后端：
- 连接成功（收到任何 HTTP 响应）→ 执行 API 测试
- 连接失败（ConnectionRefused、超时等）→ 跳过 API 测试，只执行单元测试

### 测试用户
API 测试会在 session 级别自动注册一个随机测试用户（`testuser_{uuid}`）并登录获取 JWT token，无需手动准备测试数据。每个 pytest session 只注册一次，所有 API 测试共享同一个 token。

### 运行示例
```bash
# 启动 Java 后端后运行
cd python-ai
python -m pytest test/test_api_*.py -v

# 输出示例：
# test_api_auth.py::TestRegister::test_register_success PASSED
# test_api_auth.py::TestLogin::test_login_success PASSED
# test_api_chat.py::TestChatSession::test_create_session PASSED
# ...
# 45 passed in 2.67s
```


## 新增测试规范

1. **单元测试文件命名**：`test_<模块名>.py`
2. **API 测试文件命名**：`test_api_<业务域>.py`
3. **类命名**：`Test<函数名>` 或 `Test<接口名>`
4. **用例命名**：`test_<场景描述>`
5. 每个测试用例只验证一个行为
6. 使用 `pytest.raises` 测试异常场景
7. API 测试使用 `auth_headers` fixture 自动携带 JWT token
8. 测试数据尽量使用随机值避免冲突
9. 文件上传测试使用白名单允许的类型（如 PNG），不使用 txt
10. 不存在资源的断言接受多种状态码（如 400/404），适应不同后端实现
